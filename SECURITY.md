# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately** through GitHub's private
vulnerability reporting. Do **not** open a public issue for security problems.

### How to report

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** (GitHub Security Advisories).
3. Fill in the affected versions and any reproduction details you can share.

GitHub private security advisories are the **sole supported private reporting
channel** for this repository. Please do not send reports via public issues,
pull requests, or other channels.

## What to expect

- **Acknowledgment:** We aim to acknowledge new advisories within a few business
days.
- **Triage:** Advisories are reviewed and moved out of the *Triage* state as soon
  as a maintainer has assessed them.
- **Updates:** If you have not heard back, feel free to add a comment to the
  advisory itself — this keeps the discussion private and notifies maintainers.

Thank you for helping keep this project and its users safe.
